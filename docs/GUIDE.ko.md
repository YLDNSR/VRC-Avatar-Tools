# VRC Avatar Tools — 사용 가이드

VRChat 아바타(VRM으로 내보낸 것)를 데스크톱에 띄우고, 웹캠·iPhone으로 움직이며, OBS로 방송할 수 있는 앱입니다.
뷰어와 캡처 앱이 한 앱 안에 들어 있고, 둘은 **VMC 프로토콜(UDP)** 로 통신합니다.

| 항목 | 내용 |
|---|---|
| 아바타 형식 | `.vrm` (VRM 0.x / 1.0), `.glb`, `.gltf` — VRChat 아바타는 Unity에서 VRM으로 내보내기 |
| OBS 출력 | **Syphon** 출력 — 맥용 OBS에 「Syphon Client」가 기본 내장 |
| 캡처 앱 | 메뉴 「파일 → 캡처 앱 열기」(⌘⇧C) |
| 아바타 프로필 폴더 | `~/Library/Application Support/VRC Avatar Tools/avatar_profiles` (스트리밍 패널의 「폴더 열기」) |
| 제스처 단축키 | Shift + F1～F8. 맥 키보드에서는 **fn + Shift + F1～F8** 이 필요할 수 있습니다 |

---

## 1. 설치

1. `VRC-Avatar-Tools-<버전>-mac-arm64.dmg` 를 열고 앱을 「응용 프로그램」으로 끌어 놓습니다. (Apple Silicon Mac 전용. Windows는 아래 「Windows 판」)
2. 처음 실행할 때 「확인되지 않은 개발자」 경고가 나오면 Finder에서 앱을 **Control-클릭 → 열기** 하세요. (직접 빌드한 앱이라 Apple 공증이 없습니다)
3. 캡처 앱에서 카메라·마이크를 처음 쓸 때 macOS가 권한을 묻습니다. 허용하세요.

## 2. VRChat 아바타 준비 (VRM으로 내보내기)

VRChat 아바타는 Unity 프로젝트에서 VRM으로 내보낸 뒤 엽니다.

### A. 전용 익스포터로 한 번에 (추천)

이 저장소의 `unity-exporter/` 는 VRChat 아바타 프로젝트(VCC)에 넣는 Unity 에디터 확장입니다. 자세한 설치·대상 버전은 [unity-exporter/README.md](../unity-exporter/README.md).

1. `unity-exporter` 폴더를 아바타 프로젝트의 `Packages/local.vrcavatartools.exporter/` 로 복사 (또는 VCC의 User Package로 추가)
2. `Tools → VRC Avatar Tools → Install UniVRM (VRM 1.0)` 으로 UniVRM 설치 (이미 있으면 생략)
3. **플레이 모드가 아닌 상태에서** Hierarchy의 아바타 루트 우클릭 → **VRC Avatar Tools → Export** → 저장 위치 선택
4. `<이름>.vrm` 과 `<이름>.vavmeta.json` 이 같은 폴더에 생깁니다. `.vrm` 을 뷰어에 끌어다 놓으면 `.vavmeta.json` 도 자동으로 읽습니다.

- 업로드할 때와 같은 빌드(VRChat SDK 전처리: Modular Avatar·NDMF·Avatar Optimizer·VRCFury 등)를 임시 복사본에 적용한 뒤 내보내므로, 메뉴·의상·초기 모습이 VRChat과 같습니다. 원본은 바뀌지 않습니다.
- lilToon(및 기타 셰이더) 머티리얼은 VRM MToon으로 변환됩니다: 색 조정·2nd/3rd 텍스처·알파 마스크는 텍스처에 굽고, 그림자색·경계, 림, MatCap, 발광, 노멀맵, 아웃라인을 옮깁니다.
- `.vavmeta.json` 에는 Expression Menu(아이콘 포함)·Parameters와 Gesture·Action·FX 애니메이터 전체(스테이트·트랜지션·블렌드 트리·Parameter Driver·레이어 제어), 모든 클립이 들어갑니다. 휴머노이드 애니메이션(춤·AFK 등)은 Unity에서 이 아바타에 맞춰 구워 넣습니다. 형식: [vavmeta.md](vavmeta.md)
- PhysBone → VRM SpringBone(근사), 비셈 `vrc.v_aa/ih/ou/e/oh` → VRM 입 모양, 눈 깜빡임 → `blink/blinkLeft/blinkRight`
- 꺼져 있는 오브젝트·교체용 머티리얼도 함께 내보냅니다. 뷰어는 VRChat처럼 처음엔 숨기고, 교체 머티리얼은 처음 쓸 때 불러옵니다.

### B. 직접 변환

1. 아바타 Unity 프로젝트(VCC)에 **UniVRM** 을 설치합니다. (https://github.com/vrm-c/UniVRM/releases)
2. VRChat 전용 설정(PhysBones, 표정, 시선)을 VRM으로 옮기려면 **VRM Converter for VRChat**(BOOTH 배포)를 함께 쓰면 편합니다. PhysBones → VRM SpringBone, 비셈(vrc.v_aa 등) → VRM 표정으로 변환됩니다.
3. Hierarchy에서 아바타 루트를 선택하고 `VRM0 → Export UniVRM-0.xx` 또는 `VRM1 → Export VRM 1.0` 으로 `.vrm` 을 저장합니다.
4. 이 방법으로는 Expression Menu·FX 제스처/토글이 옮겨지지 않습니다(뷰어는 VRM 표정과 블렌드셰이프·오브젝트 표시로 대신).

셰이더(lilToon, Poiyomi 등)는 어느 방법이든 VRM의 MToon/glTF 머티리얼로 바뀌므로, VRChat과 색감이 조금 다를 수 있습니다.

> VRM으로 변환하지 않은 `.glb` 도 열 수 있습니다. T포즈 모델이면 본 이름으로 휴머노이드를 자동 인식해서 애니메이션·모션 캡처가 동작합니다. 「あ・い・う・え・お」, 「まばたき」, `vrc.v_aa`, `vrc.blink` 같은 VRChat/MMD식 블렌드셰이프도 자동으로 찾습니다.

## 3. 아바타 표시하기

세 가지 방법이 있습니다.

| 방법 | 절차 |
|---|---|
| **A. 드래그 앤 드롭 (추천)** | `.vrm` 파일을 뷰어 창에 끌어다 놓습니다. Dock 아이콘에 놓아도 됩니다 |
| **B. 「아바타 파일 열기」** | 시작 화면 버튼 또는 ⌘O → 파일 선택 |
| **C. 「폴더에서 선택」** | 폴더를 고르면 썸네일 목록이 나옵니다. 오른쪽 위 검색란으로 거르면 「필터 적용 중」이 표시되고, 「×」로 지웁니다. 아래쪽 「뒤로」·「폴더 다시 선택」. 고른 폴더는 다음 실행 때 바로 열립니다 |

- 열려 있는 파일을 다시 내보내면(덮어쓰기) **자동으로 다시 불러옵니다.** 카메라 위치는 유지됩니다.

## 4. 기본 조작

| 조작 | 동작 |
|---|---|
| 왼쪽 드래그 | 아바타 회전 (세로 드래그는 카메라 높이) |
| 오른쪽 드래그 | 아바타 평행 이동 — 흔들리는 부분이 반응합니다 |
| 오른쪽 클릭 (드래그 없이) | **원형 메뉴** — 커서 주위에 아바타 메뉴가 원형으로 열립니다 (아래) |
| 스크롤 / 트랙패드 두 손가락 | 줌 인 / 아웃 |
| 더블 클릭 | 위치·크기·회전과 카메라 초기화 |
| ↑ ↓ ← → | 시점 회전 (오빗) |
| Control(또는 ⌘) + 방향키 | 시점 평행 이동 |
| + / - | 줌 |
| Shift + F1～F8 (fn 필요할 수 있음) | 제스처·표정 (왼쪽 Shift = 왼손, 오른쪽 Shift = 오른손) |
| I | 정보 오버레이 (FPS·시스템·아바타 정보·경고) |
| Esc | 열린 패널 닫기 |

화면 아래쪽에 마우스를 가져가면 **툴바**가 나타납니다: 뒤로 / 아바타 파일 열기 / 애니메이션 플레이어 / 배경 투명 전환 / 스트리밍 모드 / **위치 고정**(자물쇠) / 설정 메뉴.

「위치 고정」을 켜면 위의 드래그·스크롤·더블 클릭·방향키·+/- 로 아바타와 카메라가 움직이지 않습니다(방송 중 실수 방지). 다시 누르면 풀립니다.

데스크톱 캐릭터 동작(베타)을 켜고 배경을 투명하게 하면 마우스 조작이 **데스크톱 캐릭터 조작**으로 바뀝니다(아래 「데스크톱 캐릭터 동작」).

## 5. 편리한 기능

### 애니메이션 플레이어
- 지원 파일: `.vrma`, Unity `.anim`
  - `.anim` 의 **휴머노이드(머슬) 커브는 근사 변환**됩니다. Unity가 아바타마다 쓰는 내부 보정값이 파일에 없어서, Unity 기본 머슬 범위로 계산합니다. 블렌드셰이프(`blendShape.*`)와 오브젝트 ON/OFF(`m_IsActive`) 커브도 재생됩니다.
- **단일 / 재생목록 / 세트**: 세트는 최대 10개, 세트당 10개 항목. 마지막으로 고른 세트가 자동 복원됩니다.
- 재생·일시정지·정지·이전·다음·반복(반복 안 함 / 한 곡 / 전체), 속도
- **받침대 크기**, **Y 오프셋**(재생 중 아바타 높이), **정면으로 보기**

### 원형 메뉴 (아바타 오른쪽 클릭)
- 아바타를 오른쪽 클릭하면 VRChat의 액션 메뉴처럼 커서 주위에 원형 메뉴가 열립니다. 배경 투명 모드에서도 아바타 위를 오른쪽 클릭하면 됩니다.
- 조각마다 아바타 메뉴의 아이콘·이름이 나오고, 켜져 있는 토글은 파랗게 표시됩니다. 서브메뉴는 같은 자리에서 열리고, 가운데 버튼은 「뒤로」(맨 위에서는 「닫기」)입니다. 메뉴 위에서 오른쪽 클릭해도 뒤로 갑니다.
- 버튼은 누르고 있는 동안 동작합니다. 래디얼 퍼펫(예: 헤어 색)은 원을 따라 드래그하는 다이얼(맨 위가 0 %, 시계 방향), 2축·4축 퍼펫은 놓으면 가운데로 돌아오는 스틱이 됩니다.
- 마지막 조각 「앱」: **창 이동**, 배경 투명 켜기/끄기, 위치 고정, 정면으로 보기, 아바타 메뉴·애니메이션·위치·크기·회전·설정 창 열기, **프로그램 종료**(배경 투명 상태에서도 바로 끝낼 수 있음) (`.vavmeta.json` 이 없는 아바타는 이 항목들만 나옵니다)
- 「동작」 조각(데스크톱 캐릭터 동작이 켜져 있을 때): 기지개·두리번·하품 같은 행동을 바로 시키거나 「대기 동작」을 켜고 끕니다.
- Esc, 바깥 클릭, 다른 앱 클릭으로 닫힙니다. 위치가 고정되어 있어도 메뉴는 열립니다.

### 위치·크기·회전 (설정 메뉴 → 위치·크기·회전)
- **아바타**: 좌우·높이·앞뒤 위치(m), 회전(좌우), 기울기(앞뒤·좌우), **크기**(배율, 받침대도 함께) — 마우스로 움직이면 숫자도 따라 바뀝니다. 항목마다 ↺ 로 기본값.
- **카메라**: 거리(줌), 보는 높이 각도, 보는 방향, 시점 높이, 시야각
- **현재 상태 저장**: 위 값을 **아바타별로** 저장합니다(파일 이름 기준이라 다른 폴더에 다시 내보낸 같은 아바타도 같은 값을 씀). 「아바타를 열 때 저장값 적용」이 켜져 있으면 다음에 열 때 그대로 시작합니다.
- **저장값 불러오기**: 이 아바타의 저장값(없으면 가장 최근 저장값)으로 되돌립니다. 스트리밍 패널의 「카메라 위치 저장/복원」도 같은 저장값을 씁니다.
- **초기화**: 원점·정면·크기 1, 카메라는 전신이 보이는 위치(시야각은 유지).
- **위치·크기·회전 고정**: 툴바의 자물쇠와 같습니다. 고정 중에는 이 패널의 값도 바꿀 수 없고(저장은 가능), 「불러오기」·「초기화」·「정면으로 보기」도 막힙니다.

### 조명 (설정 메뉴 → 조명)
프리셋 6종(기본·왼쪽·오른쪽·위쪽·정면·사용자), 방향, 높이(-90°～90°), 밝기(0～1, 배경 밝기도 연동), 색온도(4200K～9600K, 기본 6500K), 사용자 설정 저장, **라이트 고정**(월드/아바타), **마커**, 항목별·전체 초기화. 앱을 닫아도 유지됩니다.

### 제스처·표정 (Shift + F1～F8)
F1 뉴트럴, F2 주먹, F3 보, F4 가리키기, F5 브이, F6 락앤롤, F7 권총, F8 엄지 척. 손가락 포즈가 바뀌고 표정이 바뀝니다. VRM 표정은 5종이라 F2～F6에 기쁨·화남·슬픔·편안·놀람이 대응합니다. 같은 키를 다시 누르면 뉴트럴로 돌아갑니다.
- 아바타 옆에 `.vavmeta.json`(전용 익스포터)이 있으면 GestureLeft/GestureRight가 아바타의 FX·Gesture 레이어로 들어가 VRChat과 같은 표정·손 모양이 됩니다. FX에 없는 제스처는 표정이 바뀌지 않습니다.
- **표정 전환 키를 항상 활성화**: 뷰어가 다른 창 뒤에 있어도 동작합니다. macOS **입력 모니터링** 권한이 필요합니다(시스템 설정 → 개인정보 보호 및 보안 → 입력 모니터링). 키 입력을 가로채지 않습니다.

### 커서 시선 모드 · 받침대
- 커서 시선 모드: 아바타 시선(과 머리 약간)이 화면 어디에 있든 마우스 커서를 따라갑니다.
- 받침대: 표시/숨기기. 발밑 높이에 자동으로 맞춰집니다.

### 표정·파라미터 패널 / 아바타 메뉴
- **메뉴** 보기: Expressions(감정), 입, 눈, 시선, 커스텀 표정, **오브젝트 표시**(옷·액세서리 ON/OFF)
- **전체** 보기: 모든 블렌드셰이프(검색 가능)
- 바뀐 항목은 노란색, 카테고리별 「초기화」, 「전체 파라미터 리셋」
- **`.vavmeta.json` 이 있으면** 패널이 「아바타 메뉴」가 되어 VRChat에서 보는 Expression Menu만 그대로(같은 이름·아이콘·토글·버튼·서브메뉴·퍼펫) 보여 줍니다. 값을 바꾸면 아바타의 애니메이터가 VRChat처럼 움직입니다: 옷·헤어 교체, 색 교체(머티리얼), 블렌드셰이프, Parameter Driver, 춤 같은 Action 레이어 애니메이션까지. 토글해도 목록 위치는 그대로이고, 서브메뉴별 스크롤 위치도 기억합니다. 「메뉴 값 초기화」는 Expression Parameter 기본값으로 되돌립니다.

### 아바타 내장 애니메이션 (애니메이션 플레이어)
- `.vavmeta.json`(v2)이 있으면 애니메이션 플레이어 아래에 아바타에 들어 있는 휴머노이드 애니메이션(춤·AFK·Idle 등)이 나오고, 눌러서 바로 재생할 수 있습니다.
- 「AFK 상태」를 켜면 VRChat에서 자리를 비웠을 때처럼 아바타의 AFK 애니메이션이 재생됩니다.
- 메뉴에 들어 있는 춤은 「아바타 메뉴」에서 켜면 VRChat과 같은 순서(인트로 → 루프 → 종료)로 재생됩니다.

### 배경 투명 모드
- 툴바의 「배경 투명 전환」. 창 테두리와 **아래쪽 툴바가 사라지고** 아바타만 남습니다. 이때는 아바타를 오른쪽 클릭해 원형 메뉴로 조작합니다(「앱 → 배경 투명」으로 끄기).
- **항상 위**, **클릭 통과**(투명한 곳의 클릭이 뒤 앱으로 전달), **해제 단축키**(기본 Option — 누르는 동안 어디서나 조작)
- 창 이동: 아바타 오른쪽 클릭 → 「앱 → 창 이동」을 누르면 이동 핸들(✥)이 나타납니다. 핸들이나 아바타를 끌면 창이 따라오고, 놓으면 끝납니다(Esc·오른쪽 클릭으로 취소).
- **아바타 투과 모드**: 투명 모드에서만. 마우스를 아바타 위에 올리면 0.15초에 걸쳐 흐려지고, 단축키(기본 Control)를 누르면 즉시 불투명. 앱을 끝내면 꺼집니다.

### 움직임이 없을 때 FPS 낮추기
OFF / On(셰이더 고려) / ON. 유휴 시 약 5fps, 창을 최소화하면 약 1fps.

### 시작 (설정 메뉴 → 시작)
- **로그인 시 자동 실행**: Mac에 로그인하면 뷰어가 자동으로 열립니다. 시스템 설정 → 일반 → 로그인 항목에도 「VRC Avatar Tools」로 나오며, 거기서 꺼도 됩니다. 「허용 필요」가 뜨면 같은 화면에서 허용해 주세요.
  - 켠 위치의 앱이 등록됩니다. 앱을 다른 폴더(예: 응용 프로그램)로 옮겼다면 옮긴 앱에서 다시 켜 주세요. 같은 위치에 새 버전을 덮어쓰는 것은 괜찮습니다.
  - 개발 모드(`npm run dev`)에서는 쓸 수 없습니다.
- **아바타별로 메뉴 값·모션 기억** (기본 켬): 아바타 메뉴의 값(의상·헤어·색·토글·춤 등)과 AFK 상태, 재생 중인 모션을 아바타마다 자동으로 저장해 두었다가, 다음에 그 아바타를 열 때 그대로 적용합니다. 일반 VRM은 표정·파라미터 패널의 표정·블렌드셰이프 값과 오브젝트 표시를 기억합니다. Unity에서 다시 내보내 자동으로 다시 불러올 때도 유지됩니다. 처음 상태로 되돌리려면 아바타 메뉴의 「메뉴 값 초기화」를 누르세요.
- **시작할 때 마지막 상태로 열기**: 시작 화면 대신 마지막에 연 아바타를 바로 표시하고, 배경 투명 모드였다면 그대로 시작합니다. 저장한 위치·크기·회전(「아바타를 열 때 저장값 적용」)과 함께 쓰면 로그인하자마자 항상 같은 모습으로 나타납니다.

자동 / 日本語 / English / 简体中文 / 한국어 / ไทย

## 6. 캡처 앱 (아바타 움직이기)

메뉴 「파일 → 캡처 앱 열기」(⌘⇧C) 또는 뷰어 설정 메뉴의 「캡처 앱 열기」.

```
웹캠 ──▶ 캡처 앱 ──VMC/UDP:39539──▶ 뷰어 ──Syphon / 투명 창──▶ OBS
iPhone(iFacialMocap) ──▶ 캡처 앱 ──VMC──▶ 뷰어
```

### 1-2. 웹캠
「카메라」「해상도」「FPS」를 고르고 「카메라 시작」. 상반신이 화면에 들어오게, 밝은 곳에서.
- 「몸 추정 정확도」(가볍게/정확하게), 「손가락 추적」, 「미러」(거울처럼 움직이기), 「랜드마크 표시」
- 추정은 MediaPipe(얼굴 478점 + ARKit 52종 블렌드셰이프, 몸 33점, 손 21점×2)로 이 Mac 안에서만 합니다.

### 1-3. iFacialMocap 전용
1. iPhone에서 iFacialMocap 실행 → 표시된 IP 확인
2. 「카메라」를 「카메라 없음 (iFacialMocap 사용)」으로
3. 「iFacialMocap IP 주소」 입력 → 「iFacialMocap 사용」 ON
4. 상태: 중지 중 / IP 미입력 / 연결 대기 중 / **수신 중**
5. 「초기 캘리브레이션」 → 「전송 시작」
- IP가 안 보이면 iFacialMocap 설정의 「대상 설정 초기화」 후 재실행. Mac 방화벽이 UDP 49983 수신을 막지 않는지 확인하세요.
- 웹캠과 같이 쓰면 표정·머리는 iFacialMocap, 몸은 웹캠에서 가져옵니다.

### 1-4. 동작 조정
상반신·팔: 안정화 / 응답성 / 동작량, 손: 전후, 눈: 동작량 / 상하 위치 / 감기 쉬움 / 뜨기 쉬움. 앱을 닫으면 자동 저장.

### 1-5. 캘리브레이션
카운트다운(0·3·5·10초) 후 정면을 보고 가만히 있는 자세를 기준으로 기록합니다. 처음엔 「초기 캘리브레이션」, 이후 「재캘리브레이션」.

### 1-6. 전송 부위
표정 / 머리 / 팔 / 상반신 / 하반신. OFF인 부위는 기본 자세(팔은 내린 자세)로 멈춥니다. 의자에 앉아 방송하면 하반신 OFF, 다른 표정 도구를 쓰면 표정 OFF.

### 1-7. 립싱크
「ON으로 설정」, 「마이크」 선택, 음량 미터. ON이면 마이크 음량·모음 분석이 웹캠 입 모양보다 우선합니다.

### 2. 뷰어와 연결
1. 뷰어: 아바타 표시 → 툴바 「스트리밍 모드」 → 연결 방법 「VMC 프로토콜」, 수신 포트 `39539` → 「시작」
2. 캡처 앱: 전송 대상 IP `127.0.0.1`, VMC Port `39539` → 캘리브레이션 → 「전송 시작」
3. 캡션 「전송 타입: VMC」 또는 「전송 타입: VMC + VRChat OSC」(표정 형식 VRCFT일 때)

**전송 시작 조건**: 웹캠 — 카메라 실행 중 + 초기 캘리브레이션 완료 / iFacialMocap — 「카메라 없음」 + 「수신 중」 + 초기 캘리브레이션 완료.

**다른 Mac/PC로 보내기**: 「전송 대상 IP」를 뷰어 쪽 IP로. 뷰어 쪽 방화벽에서 UDP 39539 허용. 같은 LAN·유선 권장.

### 스트리밍 패널 항목 (뷰어)
- **IK (팔 위치 보정)**: 손이 몸통 안으로 파고들지 않게 팔을 바깥으로 보정 (기본 OFF)
- **시야각**: 작을수록 평면적, 클수록 광각 (피사체 크기는 유지)
- **줌 강조**: 머리를 앞뒤로 움직이면 카메라가 따라 줌
- **정면으로 보기**: 위치는 그대로, 방향만 정면
- **카메라 위치 저장/복원**: 아바타 위치·크기·회전과 카메라(시야각 포함). 「설정 → 위치·크기·회전」의 저장값과 같습니다
- **모션 스무딩**: 머리·몸·손/팔·시선·깜빡임·눈썹·입 (오른쪽일수록 부드럽고 지연 증가, VRCFT 표정에는 미적용)
- 다른 VMC 송신 앱(VSeeFace, Webcam Motion Capture, Warudo 등)에서 보내는 데이터도 받을 수 있습니다.

## 7. 페이스 트래킹 (표정 형식)

| 캡처 앱 「표정 전송 형식」 | 뷰어 「페이스 트래킹 → 타입」 | 내용 |
|---|---|---|
| VRM 표준 | VRM/VRChat 기본 | 깜빡임(좌우), 모음 A·I·U·E·O, 시선(눈 본), 눈썹 5종 |
| Perfect Sync | Perfect Sync | ARKit 52종 블렌드셰이프 |
| VRCFT | VRCFT | VRChat OSC `/avatar/parameters/v2/*` (Unified Expressions) |

- 뷰어의 「타입」 버튼은 누를 때마다 VRM/VRChat 기본 → Perfect Sync → VRCFT 순으로 바뀝니다. 아래 「사용 가능:」에 이 아바타가 지원하는 형식이 표시됩니다.
- VRCFT를 고르면 VMC 외에 VRChat OSC 수신 포트(기본 `9000`)도 엽니다. 이때 표정 강도 슬라이더는 적용되지 않습니다.
- 뷰어는 VRCFT 파라미터를 아바타의 Unified Expressions 블렌드셰이프 → ARKit 블렌드셰이프 순으로 찾아 움직이고, 둘 다 없으면 VRM 기본 표정(깜빡임·입)으로 대신 움직입니다.
- **표정만 VRCFaceTracking에 맡기기**: 캡처 앱 모션 송신은 그대로, 캡처 앱 「표정」 송신 OFF → VRCFaceTracking 실행 → 뷰어 타입 VRCFT로 수신 ON. (VRCFaceTracking은 Windows 앱이라 다른 PC에서 실행하고, OSC 대상을 이 Mac의 IP:9000 으로 지정하세요.)

## 8. VRChat 페이스 트래킹 송신 (VRChat OSC)

캡처 앱의 「VRChat OSC」 버튼을 ON 하면 표정을 `/avatar/parameters/v2/<이름>` 으로 약 30fps 보냅니다 (뷰어 없이도 동작, VMC 송신과 동시 사용 가능).
- VRChat은 Quick 메뉴 → Options → OSC → **Enabled** ON. 동작이 이상하면 `Reset Config`.
- 아바타가 VRCFaceTracking(Unified Expressions)에 대응해야 합니다.
- VRChat은 macOS에서 직접 실행되지 않으므로, VRChat을 실행 중인 PC의 IP를 「VRChat 대상 IP」에 넣으세요.

| **Syphon (추천)** | 고화질·저지연, 투명 정보 전달, **플러그인 불필요** | — |
| 배경 투명 + 윈도우 캡처 | 데스크톱 마스코트로도 사용 | 화질·부하 면에서 불리 |

### Syphon
1. 뷰어: 아바타 표시 → 툴바 「스트리밍 모드」 → 「Syphon 출력 (OBS)」 → 송신 이름·해상도(창 크기 / 720p / 1080p / 1440p / 4K / 세로 1080×1920 / 1080×1080)·FPS(30/60) → 「출력 시작」

|---|---|

## 10. 아바타 프로필 (표정 블렌드셰이프 맵)

VMC로 받은 표정(Joy / A / Blink …)을 아바타의 특정 블렌드셰이프에 할당합니다. 아바타 1개당 `.toml` 1개.

1. 스트리밍 패널 「아바타 프로필」 → **폴더 열기**
2. `sample.toml` 을 복사해 이름을 바꾸고 편집 (`sample.toml` 은 목록에 안 보입니다)
3. 「목록 새로고침」 후 선택. 「없음」이면 자동 할당만 사용합니다.

```toml
name = "내 아바타"

[[expressions]]
source = "Joy"          # 받는 표정 이름 (대소문자 무관)
target = "笑い"          # 아바타 블렌드셰이프 이름
renderer = "Body"       # (생략 가능) 메시 오브젝트 이름
min_weight = 0          # (생략 가능) 0~100
max_weight = 80         # (생략 가능) 0~100
```

- source: `Joy Angry Sorrow Fun Surprised neutral`, `A I U E O`, `Blink Blink_L Blink_R`, `LookUp LookDown LookLeft LookRight`, `browDownLeft browDownRight browInnerUp browOuterUpLeft browOuterUpRight` (Perfect Sync 형식이면 ARKit 이름도 사용 가능)
- 같은 source로 블록을 여러 개 쓰면 여러 블렌드셰이프를 동시에 움직입니다.
- 이름이 틀리면 정보 오버레이(I)의 「경고」에 표시됩니다.
- 수신 값은 min_weight～max_weight 사이에서 선형 보간됩니다. 표정이 과하면 max_weight를 낮추세요.

## Windows 판 (시험판)

0.3.0부터 같은 앱을 Windows x64로도 배포합니다. 맥에서 크로스 빌드한 것이라 **실제 Windows에서는 아직 충분히 시험하지 못했습니다.** 문제가 있으면 알려 주세요.

- **설치**: `VRC-Avatar-Tools-<버전>-win-x64-setup.exe` 를 실행합니다(설치 폴더 선택 가능, 바탕화면 바로 가기). 설치 없이 쓰려면 `…-win-x64.zip` 을 풀고 `VRC Avatar Tools.exe` 를 실행하세요.
  - 코드 서명이 없어 처음 실행할 때 「Windows의 PC 보호」(SmartScreen)가 뜰 수 있습니다: 「추가 정보 → 실행」.
  - `.vrm` / `.glb` / `.gltf` 를 이 앱으로 열 수 있게 등록됩니다(「연결 프로그램」).
- **창**: 배경 투명 모드를 위해 테두리 없는 창이라, 오른쪽 위의 최소화·닫기 버튼과 위쪽 막대 드래그로 창을 다룹니다. 창 가장자리로 크기를 바꿀 수 없으므로 **설정 → 창 크기**에서 고르세요.
- **OBS**: Syphon은 macOS 전용입니다. OBS에서 「윈도우 캡처」로 뷰어 창을 잡고, 배경을 지우려면 배경색을 단색으로 두고 「크로마 키」 필터를 쓰세요.
- **표정 전환 키를 항상 활성화**: Shift+F1～F8을 전역 단축키로 등록합니다(왼손으로 처리, 다른 앱에서 이 키를 쓸 수 없게 됨). 입력 모니터링 권한은 필요 없습니다.
- **클릭 통과**: 아바타가 없는 투명한 곳은 클릭이 뒤로 전달되고, 아바타·툴바 위에서는 조작할 수 있습니다. 「해제 단축키」(누르는 동안 어디서나 조작)는 Windows에서는 동작하지 않습니다.
- **로그인 시 자동 실행**: Windows 시작 프로그램에 등록됩니다(설정 → 앱 → 시작 프로그램).
- 설정·아바타 프로필 폴더: `%APPDATA%\VRC Avatar Tools`
- 카메라·마이크는 Windows 설정 → 개인 정보 → 카메라/마이크에서 데스크톱 앱 접근이 허용되어 있어야 합니다.

## 데스크톱 캐릭터 동작 (베타)

아바타가 화면에 가만히 서 있지 않고 스스로 움직이는 실험 기능입니다. 모션 파일 없이 뷰어가 직접 만듭니다.

- **대기 동작**: T자 자세 대신 팔을 편하게 내리고(팔이 저절로 살짝 흔들림), 숨을 쉬고(들숨이 날숨보다 빠름), 눈을 깜빡이고, 가끔 체중을 한쪽 다리로 옮깁니다(골반이 그쪽으로 옮겨 가고 반대쪽 무릎이 풀리며 뒤꿈치가 살짝 듦). 발은 골반 너비쯤 벌리고 발끝을 살짝 바깥으로 둔 채 서고, 가끔 서는 방식을 바꿉니다(조금 넓게 · 조금 좁게 안짱다리로 · 한 발 앞으로). 발을 옮길 때는 먼저 반대쪽 다리로 체중을 싣고 한 발씩 딛습니다. 한쪽 다리로 서 있는 동안 쉬는 발을 살짝 앞으로 내디뎠다가, 체중을 옮기기 전에 다시 거두기도 합니다. 시선은 대부분 카메라(보는 사람)를 향하고, 가끔 옆이나 아래를 봅니다. 눈이 먼저 움직이고 고개가 뒤따릅니다.
- **전신 동작**: 상반신이 움직이면 하반신도 따라 움직입니다. 상체를 숙이면 골반이 뒤로 빠지고, 옆으로 기울이면 반대로 균형을 잡습니다. 무릎은 다리 IK로 계산하고, 발은 바닥에 붙은 채 제자리에 있거나(걸음·까치발·발 구르기 때만 움직임) 자연스럽게 따라옵니다. 동작이 끝나면 몸이 먼저, 팔과 손이 조금 늦게 제자리로 돌아오고, 한쪽 다리로 체중을 옮기며 숨을 크게 내쉽니다. 방송 중에는 상반신 위주로 움직이고 발은 서 있던 자리에 둡니다(발 옮기기 없음). 서는 방식은 「가끔 자세 바꾸기」가 켜져 있을 때만 바뀌고, 꺼져 있으면 골반 너비로 서 있습니다.
- **작은 몸짓**: 가끔 보는 사람에게 미소 짓기, 고개 갸웃(골반은 반대쪽으로), 작은 끄덕임, 까치발, 이쪽저쪽 다리로 흔들흔들, 어깨 으쓱, 한쪽 뒤꿈치 들기를 합니다. 딴 곳을 보다가 다시 쳐다볼 때 웃기도 합니다.
- **자세 바꾸기**: 가끔 손을 앞으로 모으거나 뒷짐을 졌다가 다시 팔을 내립니다.
- **혼자 하는 행동**: 가끔 기지개(까치발로 손을 머리 위로 모으고 좌우로), 두리번(보는 쪽 다리로 체중을 옮기며 골반도 돌아감), 하품, 머리 넘기기, 흥얼흥얼(뒷짐 지고 이쪽저쪽 다리로), 꾸벅꾸벅 졸기(무릎이 풀리다가 깜짝 놀라 한 발 짚고, 부끄러워 볼을 감쌈), 목 풀기, 손 보기, 갸웃, 손인사 등을 합니다. 빈도는 안 함 / 가끔 / 보통 / 자주.
- **표정**: 동작마다 표정이 함께 바뀝니다(웃는 눈, > < 눈, 볼 빨개짐, ω 입, 삐친 입 등). 아바타에 VRM 표정이 있으면 그것을 쓰고, 없으면 VRChat·MMD식 이름의 셰이프 키(なごみ, にっこり, はぅ, 照れ, ω, ∧ 등)를 찾아 씁니다. 해당하는 셰이프 키가 없는 아바타는 그 표정만 빠집니다.
- 켜기: 설정 메뉴 → 실험 기능 → 「데스크톱 캐릭터 동작 (베타)」. 끄면 관련 코드를 불러오지 않고, 쓰다가 끄면 원래 자세로 바로 돌아갑니다. 베타 앱은 처음부터 켜져 있고, 정식 앱은 꺼져 있습니다.
- 설정: 애니메이션 메뉴 아래 「데스크톱 캐릭터」. 혼자 움직이기 켜기/끄기, 혼자 하는 행동 빈도, 움직임 크기, 서 있는 자세(팔 내리기 · 손 모으기 · 뒷짐), 세부 설정(전신으로 움직이기, 팔 내리기, 자세 바꾸기, 숨쉬기, 체중 옮기기, 두리번거리기, 작은 몸짓, 카메라 쳐다보기, 눈 깜빡임), 「지금 해 보기」 버튼.
- 오른쪽 클릭 원형 메뉴의 「동작」에서도 행동을 바로 시킬 수 있습니다.

**데스크톱 캐릭터 조작** (기본: 배경 투명일 때. 애니메이션 메뉴 → 데스크톱 캐릭터 → 「캐릭터 조작」에서 「항상」 또는 「안 씀」으로 바꿀 수 있음)

| 조작 | 동작 |
|---|---|
| 왼쪽 클릭 | 반응: 머리 → 눈을 감고 볼을 붉히며 쓰다듬어짐(무릎을 모으고 한쪽 뒤꿈치를 듦), 몸 → 눈을 질끈 감고(> <) 손을 가슴으로 모으며 한 발 물러섬, 그다음 갸웃, 손 → 그 손을 살짝 들어 바라본 뒤 웃음, 다리·발 → 깜짝 놀라 무릎을 모으고 치마를 누르며 얼굴이 빨개짐. 몇 초 안에 여러 번 찌르면 발을 한 번 구르고 「흥!」 하고 몸을 돌렸다가 힐끔 쳐다봅니다 |
| 왼쪽 드래그 | 창 이동(아바타가 바탕화면 위를 따라 움직임). 회전하지 않습니다 |
| 오른쪽 클릭 | 원형 메뉴 |
| 아바타 위에서 스크롤 | 확대/축소. 커서가 가리키는 곳을 중심으로 커지고 작아집니다 |

- 클릭하면 보는 사람을 쳐다보고, 한동안 혼자 하는 행동을 쉽니다.
- 오른쪽 드래그(아바타를 창 안에서 옮기기)는 그대로입니다. 더블 클릭으로 화면이 초기화되지 않습니다(연속 클릭은 반응).
- 「위치 고정」 중에는 드래그 이동과 확대/축소가 막히고, 클릭 반응과 메뉴는 됩니다.
- 모션 파일이나 아바타 애니메이션(댄스, AFK)이 재생 중이면 그쪽이 먼저입니다. 팔·다리는 그 애니메이션에 맡기고(넘어갈 때 부드럽게 이어짐) 혼자 하는 행동도 쉽니다. 커서 시선 모드가 켜져 있으면 시선은 커서를 따릅니다. 트래킹(VMC)이 몸을 움직이는 동안에도 쉽니다.
- 다른 기능이 없을 때 「움직임이 없을 때 FPS 낮추기」가 켜져 있으면 대기 동작은 초당 30프레임으로 움직입니다.

## 자율 방송 (베타)

카메라 없이 아바타만으로 방송하는 실험 기능입니다. 치지직 채팅을 읽고 **이 Mac 안의** LLM과 음성으로 대답하고, 채팅이 없으면 가끔 혼잣말을 하며, 숨쉬기·고개·시선·눈 깜빡임·입 모양을 스스로 움직입니다. 방송자는 언제든 직접 끼어들어 아바타가 대신 말하게 할 수 있습니다.

### 안전장치 — 기존 기능은 그대로
- **베타 앱은 따로 설치됩니다**: 「VRC Avatar Tools Beta」는 번들 ID와 설정 폴더(`~/Library/Application Support/VRC Avatar Tools Beta`)가 달라, 지금 쓰는 앱을 덮어쓰거나 그 설정을 바꾸지 않습니다. 처음 실행할 때 기존 앱의 설정을 복사해 시작합니다. 언제든 베타 앱만 지우면 원래 상태입니다.
- **기능 스위치**: 설정 메뉴 → 실험 기능 → 「자율 방송 (베타)」. 꺼져 있으면 관련 코드를 아예 불러오지 않고, 쓰다가 끄면 방송을 멈추고 동작·표정을 바로 아바타에서 걷어냅니다. 베타 앱은 처음부터 켜져 있고, 정식 앱은 꺼져 있습니다.
- 치지직 Client Secret과 로그인 토큰은 macOS 키체인으로 암호화해 앱 안에만 저장합니다(화면에 다시 표시하지 않음).

### 시작하기
1. 아바타를 열고 하단 메뉴(또는 오른쪽 클릭 → 앱 메뉴)의 **자율 방송** → 「방송 시작」.
2. 「상반신 구도」로 머리~가슴을 맞추고(「더 가깝게」 가능), 「동작 → 이 구도 저장」으로 아바타별로 저장합니다.
3. OBS 영상: 배경 투명 ON + 스트리밍 메뉴의 **Syphon 출력**(9장). UI는 Syphon에 나오지 않으므로 패널을 열어 둔 채 방송해도 됩니다.
4. OBS 소리: 「macOS 오디오 캡처 → 응용 프로그램」에서 이 앱을 고르거나, 목소리 탭의 「출력 장치」를 가상 오디오 장치로 정해 그 장치를 OBS에 추가합니다.
- 창을 최소화하면 화면 갱신이 초당 1회로 줄어 Syphon 영상도 느려집니다. 다른 창 뒤에 두는 것은 괜찮습니다.

### 치지직 연결
1. [치지직 개발자 센터](https://developers.chzzk.naver.com/)에서 애플리케이션을 등록합니다. 로그인 리디렉션 URL은 치지직 탭에 표시된 `http://localhost:39780/chzzk/callback`, 권한은 **채팅 메시지 조회**와 **유저 정보 조회**.
2. 발급된 Client ID / Client Secret을 치지직 탭에 입력 → 저장 → 「치지직 로그인」(브라우저에서 동의) → 「채팅 연결」. 「방송 시작 시 채팅 연결」을 켜 두면 다음부터는 방송 시작만 누르면 됩니다.
- 치지직 없이 시험하려면 방송 탭 아래 「테스트 채팅」으로 시청자/방송자 채팅을 넣어 보세요.

### 대답 방식
| 방식 | 동작 |
|---|---|
| LLM 대답 | 로컬 LLM(Ollama 또는 OpenAI 호환 서버)이 캐릭터 설정대로 짧게 대답. 연결이 안 되면 채팅을 읽어 줍니다 |
| 채팅 읽기 | LLM 없이 「닉네임님, 내용」으로 읽기 (형식 변경 가능) |
| 대답 안 함 | 채팅은 기록만, 혼잣말과 직접 말하기만 |

- Ollama 설치: `brew install ollama` → `ollama serve` → `ollama pull qwen3:4b`(약 2.6GB). 대답 탭 「연결 확인」으로 모델을 고릅니다.
- `!` 로 시작하는 채팅(봇 명령)은 건너뜁니다(무시할 접두어). 금지어가 든 채팅에는 대답하지 않고, 금지어가 든 대답은 말하지 않습니다.
- 채팅이 몰리면 가장 최근 몇 개(대기 채팅 수)만 대답하고 나머지는 흐리게 표시됩니다.

### 방송자 개입
- 방송 탭 입력란에 쓰고 Enter → LLM을 거치지 않고 그대로 말합니다. 기다리던 대답보다 먼저 나오고, 「개입하면 기다리던 대답 취소」가 켜져 있으면 그 대답들은 버립니다.
- 치지직에서 **방송자 계정으로 친 채팅**도 아바타가 그대로 말합니다. 접두어(예: `!말`)를 정하면 그 접두어로 시작하는 채팅만 말합니다.
- 「자동 대답 일시정지」: 채팅 대답과 혼잣말을 멈춥니다(직접 말하기는 됨). 「지금 말 멈추기」: 말하던 문장을 끊습니다.

### 동작 · 반응 제스처
- 방송 중에는 데스크톱 캐릭터 동작(위 항목)과 같은 대기 동작에 입 모양·말할 때 표정이 더해집니다. 데스크톱 캐릭터 스위치가 꺼져 있어도 방송 중에는 움직이고(동작 탭 「대기 동작」), 서 있는 자세·혼자 하는 행동·움직임 크기는 애니메이션 메뉴의 데스크톱 캐릭터 설정을 같이 씁니다. 말하거나 대답을 생각하는 동안에는 혼자 하는 행동을 쉬고, 졸기는 방송 중에 나오지 않습니다.
- **반응 제스처**: 말할 때 어울리는 동작을 합니다. 인사·작별 → 손인사, 고마움·사과 → 꾸벅, 기쁨 → 신남, 놀람 → 놀람, 슬픔 → 시무룩, 화남 → 도리도리, 그 밖엔 가끔 끄덕. 같은 동작은 몇 초~십여 초 동안 다시 나오지 않습니다. LLM이 대답을 생각하는 동안에는 턱을 괴고 생각하는 자세를 합니다.
- 방송 탭·동작 탭의 제스처 버튼(손인사·꾸벅·끄덕·갸웃·생각·신남·놀람·시무룩·도리도리)으로 바로 시킬 수 있습니다.
- 직접 말하기(또는 방송자 채팅)에 `[손인사] 안녕하세요`처럼 태그를 넣으면 그 동작을 하며 말합니다. 태그는 읽지 않고, 태그만 쓰면 동작만 합니다. LLM도 어울릴 때 동작 태그를 붙일 수 있습니다.
- 춤·AFK처럼 아바타 애니메이션이 팔을 움직이는 중에는 팔 동작은 빼고 고개만 움직입니다.

### 목소리
- 기본은 macOS 음성(유나 등 한국어 음성). 목소리 탭에서 음성·속도·음량·출력 장치를 고르고 「들어보기」로 확인합니다.
- **내 목소리로 말하기(음성 복제)**: Qwen3-TTS 같은 로컬 TTS 서버를 띄우고 「로컬 TTS 서버」를 고릅니다. OpenAI 호환 `/v1/audio/speech` 에 `{ input, model, voice }` 를 보내 WAV를 받습니다. (서버 설치·녹음 도구는 다음 단계에서 추가 예정)

### 알려진 제한 (베타)

## 11. 알려진 차이 · 제한

- lilToon/Poiyomi 등 Unity 셰이더는 MToon으로 근사합니다(2nd 그림자, 반사(스페큘러), 머티리얼 속성 애니메이션 중 색 이외 — 예: 역광 보정 `_UseBacklight`, 알파 마스크 전환 — 은 재현되지 않음). MToon은 MatCap과 림라이트가 마스크를 하나만 쓰므로, 둘의 마스크가 다른 재질은 더 눈에 띄는 쪽만 남습니다. PhysBones는 SpringBone 근사이고 Contacts는 없습니다.
- 아바타 애니메이터는 Gesture·Action·FX 레이어를 VRChat처럼 실행하지만, Base(이동) 레이어는 뷰어 자체 Idle·애니메이션을 쓰고, VRChat 기본 이모트(proxy 애니메이션)와 사운드, 앉기·이동 관련 파라미터(속도·Grounded 등 고정값)는 재현되지 않습니다.
- 이전 버전(v1) `.vavmeta.json` 은 블렌드셰이프·오브젝트 ON/OFF 토글만 근사로 재현합니다. 새 익스포터로 다시 내보내세요.
- `.anim` 휴머노이드 클립은 근사 변환이라 손가락·팔 각도가 Unity와 조금 다를 수 있습니다.
- iFacialMocap의 머리 회전 방향은 실제 iPhone으로 시험하지 못했습니다. 방향이 반대로 느껴지면 「미러」를 바꿔 보세요.
- 맥북 키보드의 F1～F8은 기본적으로 밝기·음량 키입니다. fn을 함께 누르거나, 시스템 설정 → 키보드에서 「F1, F2 등의 키를 표준 기능 키로 사용」을 켜세요.
